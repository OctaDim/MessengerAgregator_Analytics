import pjsua as pj
import time


# Класс для обработки событий звонка
class MyCallCallback(pj.CallCallback):
    def on_state(self):
        print("Состояние звонка изменилось:", self.call.info().state_text)
        if self.call.info().state == pj.CallState.CONFIRMED:
            print("Звонок отвечен!")
        elif self.call.info().state == pj.CallState.DISCONNECTED:
            print("Звонок завершен.")

    def on_media_state(self):
        if self.call.info().media_state == pj.MediaState.ACTIVE:
            # Соединение медиа-каналов установлено
            print("Медиа-поток активен. Можно говорить.")


# Настройка библиотеки
lib = pj.Lib()
try:
    lib.init()

    # 1. Настройка транспорта с правильным портом
    transport = lib.create_transport(pj.TransportType.UDP, pj.TransportConfig(5060))  # 5060 стандартный SIP порт

    # 2. Конфигурация аккаунта со STUN (для работы за NAT)
    acc_cfg = pj.AccountConfig()
    acc_cfg.id = "sip:ваш_логин@sip.provider.com"
    acc_cfg.reg_uri = "sip:sip.provider.com"
    acc_cfg.auth_cred = [pj.AuthCred("*", "ваш_логин", "ваш_пароль")]
    acc_cfg.sip_stun_use = True  # Использовать STUN из настроек транспорта
    # acc_cfg.media_stun_use = True # Для медиа-потока (голоса)

    # Настройка STUN-сервера для библиотеки
    lib.set_null_snd_dev()  # Отключаем звуковое устройство по умолчанию для настройки
    # lib.init(ua_cfg=pj.UAConfig(stun_server="stun.provider.com:3478"))

    lib.start()

    # 3. Создание аккаунта и ожидание регистрации
    acc = lib.create_account(acc_cfg)
    print("Регистрируемся...")
    time.sleep(2)  # Даем время на регистрацию
    print("Статус регистрации:", acc.info().reg_status_text)

    # 4. Совершение звонка с callback
    if acc.info().reg_status == 200:
        lck = lib.auto_lock()
        call = acc.make_call("sip:+79991112233@sip.provider.com", cb=MyCallCallback())
        lck.release()

        # Ждем завершения звонка
        while call.is_valid() and call.info().state != pj.CallState.DISCONNECTED:
            time.sleep(1)
    else:
        print("Ошибка регистрации. Проверьте логин/пароль/сеть.")

    time.sleep(5)

finally:
    lib.destroy()



Итог: минимальный стартовый набор
    Для тестов: Установите pjsua2 на Python, получите тестовый SIP-аккаунт (можно на бесплатном публичном сервере или у VoIP-провайдера с пробным периодом), подключите гарнитуру, настройте брандмауэр.
    Для реального использования: Лучше взять аккаунт у коммерческого VoIP-провайдера, настроить STUN, использовать качественную гарнитуру или IP-телефон.
    Для продакшена: Ваш код должен стать полноценным SIP-клиентом с обработкой входящих звонков, DTMF-сигналов, повторным подключением при обрыве, детальным логированием и управлением звуковыми устройствами.
Рекомендация: Для отладки сначала используйте готовые программные телефоны (например, Zoiper, MicroSIP, Linphone), чтобы убедиться, что ваш SIP-аккаунт и сеть работают корректно. Затем переносите настройки в ваш Python-скрипт.

1. Для запуска данного Python-скрипта нужно:

Программное обеспечение:

    Библиотека PJSIP (pjsua): Это основная зависимость.

        Установка: pip install pjsua2 (обратите внимание на 2 в конце — это актуальная версия Python-обертки).

        Важно: На Windows/Linux/Mac могут потребоваться дополнительные системные библиотеки для компиляции. Проще всего установить готовые wheel-файлы для вашей ОС.

    Python: Естественно, версия 3.6+.

2. Что нужно для самого SIP-звонка (сетевая инфраструктура):

А. SIP-аккаунт у оператора (провайдера):

    Это как логин и пароль для телефонии. В коде это "sip:user@provider.com" и "password".

    Где взять:

        Платные операторы VoIP (например, Telphin, Zadarma, MTT и многие другие). Они дают номера, исходящую связь на город/мобильные, пакеты минут.

        Корпоративные АТС (Asterisk, FreePBX, 3CX, Panasonic и т.д.). Ваш аккаунт будет зарегистрирован на этой АТС.

        Бесплатные публичные серверы (для тестов, не для производства).

Б. Сетевое оборудование и настройки:

    Стабильный интернет. Важна не столько скорость, сколько низкая задержка (ping) и отсутствие потерь пакетов.

    Проброс портов (часто): Если ваш код работает за NAT (роутером), SIP-провайдеру нужно будет достучаться до вас. В коде вы слушаете порт 5080. Вам, возможно, потребуется на роутере пробросить UDP 5080 на IP-адрес вашего компьютера. На практике чаще используют технику STUN.

    STUN-сервер: Помогает клиенту за NAT узнать свой внешний IP и порт. Обычно предоставляется вашим SIP-провайдером или можно использовать публичные (например, stun.google.com:19302). В pjsua настройка AccountConfig позволяет указать STUN-сервер.

    Брандмауэр: Должен пропускать UDP-трафик на выбранных портах (обычно 5060, 5061, диапазоны 10000-20000 для медиа).

3. Оборудование (аппаратное):

Для программного телефона (softphone), которым по сути является ваш скрипт, достаточно:

    Гарнитура (наушники + микрофон) или колонки + отдельный микрофон.

    Встроенные в ноутбук динамик и микрофон (качество будет низким, возможна акустическая обратная связь).

Если вы хотите подключить физический телефон:

    IP-телефон (Cisco, Yealink, Grandstream и др.). Он сам содержит SIP-клиент и подключается к сети Ethernet. Ваш код тогда не нужен — настройки провайдера вводятся прямо в телефон.

    ATA-шлюз (например, Grandstream HT系列). Это адаптер, который подключается к сети, а к нему можно подключить обычный аналоговый телефон (DECT-трубку или старый городской аппарат).
